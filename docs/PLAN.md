# Refrain: план от идеи до 1.0

> Open-source движок распознавания речи для macOS. Живёт в строке меню и превращает звук в текст на Neural Engine. Любое приложение на Mac обращается к нему через стандартный OpenAI-совместимый API: Reprise — за транскриптами звонков, скрипты и другие приложения — за своими файлами. Pretype использует тот же движок внутри своего процесса для диктовки. Звук не покидает Mac.

Название — Refrain (см. раздел 2). Папка проекта пока `whisper`.

---

## 1. Принципы

1. **Только слух.** Refrain превращает речь в текст, и больше ничего. У него нет своей диктовки: её делает Pretype. Нет обработки текста через LLM, саммари и заметок: это работа Pretype, Granola и скриптов пользователя. Нет облака.
2. **Один движок на весь Mac.** Сейчас каждое приложение для диктовки и транскрипции носит свои модели. Refrain скачивает модели один раз, а приложения обращаются к нему через API, который уже знают: `POST /v1/audio/transcriptions`.
3. **Neural Engine, а не GPU.** Parakeet работает на ANE через Core ML. Языковая модель Pretype работает на GPU через MLX, поэтому они друг другу не мешают. Whisper large на Metal занял бы тот же GPU.
4. **Язык решают замеры.** Движок для каждого языка выбирается по WER, а не по бренду модели. Русский — язык первого класса: как раз там Apple слабее всего. Таблица замеров публикуется.
5. **Бюджет ресурсов.** В простое Refrain ничего не делает: нет таймеров, `NWListener` ждёт сокет, модель выгружена. Цифры CPU и памяти измеряются на Release-сборке и публикуются в README, как у Reprise.
6. **Приватно.** Refrain слушает только `127.0.0.1`. Звук приходит во временный файл и удаляется после ответа. Текст нигде не хранится и не пишется в лог: в логе только длительности и время обработки. Наружу уходят только загрузка моделей и проверка обновлений.
7. **Нативно и с минимумом кода.** Swift 6, SwiftUI, Network.framework, App Intents и Speech. Единственная сторонняя зависимость — FluidAudio (Apache-2.0): без неё нет Parakeet на ANE.
8. **Открытый код навсегда.** MIT, без аккаунтов и платной версии.

## 2. Название

**Refrain** — рефрен, слова, которые возвращаются в песне. Пара к Reprise: reprise в нотах — повтор музыки, refrain — повтор слов. Reprise возвращает звук разговора, Refrain — его слова. Слово короткое, произносится одинаково легко по-английски и по-русски («рефрен»).

Проверено 2026-10-12: App Store (Mac и iOS, магазины US, RU, DE, GB), товарные знаки США в классах 9 и 42, GitHub, Homebrew. У Refrain в App Store только приложения для сочинения песен и аудиолупер, расшифровки речи нет. Знаков в классах 9 и 42 нет. Каск `refrain` свободен. **До релиза:** знаки ЕС (TMview, EUIPO) и России (Роспатент) — TMview не отвечал с машины, где шла проверка.

| Кандидат | Почему нет |
|---|---|
| Libretto | В Mac App Store с 2020 года есть «Libretto • AI Speech to Text» — расшифровка на устройстве, та же ниша |
| Recitative, Partitura, Copista | Чистые, но длинные: трудно произнести и запомнить |
| Verba, Slovo, Slova, Oto, Dicta | Уже есть приложения для расшифровки речи с таким названием |
| Aria, Canto, Lyric, Ditto | Opera Aria, знаки Canto Inc., поле Lyric переполнено, `ditto` — системная утилита и каск |
| Skaz, Bukva, Zapis | Чистые, но транслит русских слов — не то направление |
| Retype | Чисто, но есть генератор документации retype (1,3k ⭐) |
| Earmark | Знак Articulate AI в классе 42: саммари встреч |
| Steno, Hearsay, Heard | Steno Dictation и Hearsay (text to speech) в App Store; Heard переполнено |
| Pinna, Parlato, Tacet, Detto, Murmur, Wispr, Verbatim, Sotto, Earshot, Hark | Отвергнуты раньше: анатомия, соседние приложения диктовки, бренд носителей данных |

### Бренд

**Суть:** не «ещё одна диктовка», а *слух Mac*: один движок, к которому обращаются все приложения.
**Обещание:** *Every word stays on your Mac.*
**Характер:** как у Reprise: тихий, точный, нативный, приватный. Refrain почти не видно, потому что это служба, а не окно.

**Логотип — направление.** У Reprise нотный знак `:‖`. У Refrain — знак дыхания из нот (`’`). В нотах он показывает, где певец берёт дыхание, а для всех остальных выглядит как кавычка, то есть как речь. Графит тот же, что у Reprise, а единственный акцент свой, не красный: красный у Reprise означает «идёт запись».

### Отличие от других

Поиск на 2026-10-12 не нашёл нативного приложения, которое отдаёт OpenAI-совместимый API для распознавания на устройстве.

| Кто | Что это | Чем Refrain иначе |
|---|---|---|
| Handy, VoiceInk, Murmur, Undertone, Pindrop | Диктовка из строки меню, часто на Parakeet через FluidAudio | Refrain не диктует сам. Он — движок для других приложений |
| SuperWhisper, Wispr Flow | Диктовка с обработкой через LLM, платно; Wispr Flow — в облаке | Только слух, без LLM и облака |
| MacWhisper | Транскрипция файлов, нативно, платно | Файлы не главное. Главное — API для любого приложения |
| speaches, parakeet-api, сервер whisper.cpp | OpenAI-совместимые серверы на Python или C++, из терминала | Нативное приложение без терминала, на ANE, с выбором движка по языку |
| Apple SpeechAnalyzer | Системный фреймворк, каждое приложение настраивает его само | Refrain использует его и добавляет Parakeet там, где Apple слаба |

VoiceInk и другие умеют ходить к своему OpenAI-совместимому серверу. Значит, они тоже могут стать клиентами Refrain.

**Позиционирование:** *Refrain — слух вашего Mac. Один движок для всех приложений, и ни одно слово не уходит наружу.*
**Для кого:** для пользователей Reprise и Pretype, для тех, кто пишет скрипты и автоматизации со звуком, и для приложений, которые уже умеют OpenAI API, но не должны отправлять звук в облако.

```
┌─────────────── Refrain.app (LSUIElement, строка меню) ───────────────┐

│  Server (NWListener, 127.0.0.1:8178)   Intents (Shortcuts, Spotlight) │
│  POST /v1/audio/transcriptions         «Transcribe File»              │
│  GET  /v1/models                                                      │
│            │                                     │                    │
│            └─────────────────┬───────────────────┘                    │
│                              ▼                                        │
│  ┌──────────────── RefrainKit (Swift package) ─────────────────┐     │
│  │  Router ──язык──▶ SpeechTranscriber │ DictationTranscriber   │     │
│  │                   │ Parakeet (FluidAudio, ANE)               │     │
│  │  чтение файла кусками · словарь · таймкоды · уступка диктовке│     │
│  └──────────────────────────────────────────────────────────────┘     │
└───────────────────────────────────────────────────────────────────────┘

  Reprise, VoiceInk, скрипты,              Pretype (диктовка)
  Obsidian, Raycast …
```

`RefrainKit` — это `Transcription.swift` и `Parakeet.swift` из Pretype, вынесенные в пакет и дополненные пакетным режимом. `DictationController` остаётся в Pretype: это 1400 строк про клавиатуру, каретку и вставку текста, а не про речь.

### 3.1 Движки и выбор по языку

Правило выбора то же, что в Pretype. Замеры сделаны в Pretype (`Eval/asr`, FLEURS-ru, 200 фраз).

| Языки | Движок | Почему |
|---|---|---|
| Языки SpeechTranscriber (en, de, fr, es, it, ja, ko, pt, zh и др.) | Apple SpeechTranscriber | Модели системные: ноль байт в приложении. На английском равен Parakeet: WER 7,8 против 6,6, доверительные интервалы пересекаются |
| Европейские языки Parakeet v3, которых нет в SpeechTranscriber (ru, uk, pl, cs и др.) | Parakeet Ultra на ANE | Русский, текст как печатается: WER 30,1 у Apple → 12,3. Пунктуация F1 0,02 → 0,85. Медиана 194 → 59 мс на фразу |
| Остальные | Apple DictationTranscriber | Хуже, но есть. WhisperKit — только когда попросят язык, которого нет нигде |

- `language` в запросе выбирает движок. Если его нет, работает Parakeet, если модель скачана (он сам определяет язык), иначе — SpeechTranscriber на языке системы.
- На de, fr и es Parakeet может оказаться точнее Apple. Это нужно измерить до того, как менять правило.
- Длинный файл никогда не читается в память целиком: час звука в 16 кГц float32 — это 230 МБ. SpeechAnalyzer сам читает `AVAudioFile` (`analyzeSequence(from:)`). Для Parakeet звук читается и переводится в 16 кГц кусками.
- Таймкоды: у SpeechTranscriber атрибут `.audioTimeRange`, у FluidAudio `TokenTiming` → `WordTiming`. Из них получаются сегменты и слова в `verbose_json`.

### 3.2 API

- `POST /v1/audio/transcriptions`, multipart, как у OpenAI:
  - `file` — любой формат, который читает AVFoundation: m4a, mp3, wav, caf, mp4.
  - `language`, `prompt`.
  - `response_format`: `json`, `text`, `verbose_json`, позже `srt` и `vtt`.
  - `timestamp_granularities[]`: `segment`, `word`.
  - `model` принимается и не учитывается: движок выбирает Refrain.
- `GET /v1/models` возвращает одну модель `auto`. Некоторые клиенты так проверяют соединение.
- Запросы выполняются по одному, остальные ждут в очереди.
- **Защита.** Сервер слушает только `127.0.0.1`. Заголовок `Host` должен быть `127.0.0.1:<порт>` или `localhost:<порт>`, это защищает от DNS rebinding. Запрос с `Origin` по схеме `http` или `https` отклоняется: такой заголовок присылает веб-страница, а нативные клиенты и Electron (`app://`) его так не присылают. Заголовков CORS нет. Размер тела ограничен. Ключ API не нужен; токен можно добавить, если появится спрос.
- Порт по умолчанию — 8178, его можно сменить в настройках. Если порт занят, Refrain показывает ошибку в строке меню и не выбирает другой порт молча: у клиентов адрес записан в настройках.

### 3.3 Словарь

Распознавание чаще всего ошибается в именах и терминах. Refrain собирает словарь из трёх источников и отдаёт его движку: до ~100 слов, без повторов.

1. **`prompt` из запроса.** Из него берутся имена и редкие слова. Это делает `biasWords(in:)` из Pretype: он уже извлекает такие слова из текста в поле ввода. Reprise уже передаёт хвост предыдущего куска, а позже будет передавать и участников встречи из календаря.
2. **Список в настройках:** имена, названия продуктов, термины. Это редактор списка, а не текстовое поле.
3. Контакты — только если попросят: для них нужно отдельное разрешение.

В движках:

- SpeechAnalyzer: `AnalysisContext.contextualStrings[.general]`. Pretype уже так делает.
- Parakeet: `configureVocabularyBoosting(vocabulary:ctcModels:)` из FluidAudio. Для этого нужна ещё одна модель (CTC 110M), то есть ещё одна загрузка. Прежде чем включать, нужно измерить выигрыш на именах. Pretype сейчас не подсказывает Parakeet слова вообще, поэтому этот выигрыш получит и он.

### 3.4 Уступать диктовке

Pretype и Refrain работают в разных процессах и делят один ANE. Транскрипция часового звонка не должна тормозить диктовку.

- **Сначала замер.** Сравнить медиану времени до первого слова в диктовке Pretype, когда Refrain транскрибирует час и когда простаивает. Если разница не видна, этот пункт не нужен.
- **Если нужен:** Pretype отправляет Darwin-уведомления `notify_post` в начале и в конце диктовки. Refrain дописывает текущий кусок и ждёт конца. IPC и общей памяти для этого не нужно, а без Pretype согласовывать нечего.

### 3.5 Память и диск

- Модели Parakeet лежат в общем кэше FluidAudio: `~/Library/Application Support/FluidAudio/Models`. Pretype и Refrain не в песочнице, поэтому скачанная один раз модель видна обоим. Модели SpeechAnalyzer системные и общие для всех приложений.
- В памяти у каждого процесса своя копия, пока он с ней работает. Замер на Release-сборке Refrain: около 700 МБ в момент загрузки Parakeet, около 90 МБ, пока модель загружена. Refrain выгружает модель через пять минут простоя.
- Refrain ничего не хранит. Нет истории и нет библиотеки: результат получает клиент.

## 5. Связь с Pretype и Reprise

### Pretype

- `Transcription.swift` и `Parakeet.swift` переезжают в RefrainKit, Pretype подключает пакет. Поведение не меняется. Проверка: тесты фазовой машины диктовки проходят, и диктовка проверена голосом.
- Потом: подсказка слов из поля ввода для Parakeet (3.3) и уведомления начала и конца диктовки (3.4), если замер покажет, что они нужны.

### Reprise

- Новый пресет *Refrain (this Mac)*: `http://127.0.0.1:8178/v1`, модель `auto`, без ключа. Это одна строка в списке пресетов `Transcriber.swift`. Reprise по-прежнему не содержит стороннего кода.
- Настройки транскрипции Reprise могут проверить `GET /v1/models` и предложить пресет, если Refrain запущен.
- Reprise уже шлёт куски по 10 минут, `response_format=json`, `language` и хвост предыдущего куска в `prompt`. Refrain принимает всё это без изменений.
- Позже: Reprise отправляет `you.m4a` и `them.m4a` отдельно с `verbose_json` и собирает `transcript.json` с сегментами «Вы / Собеседники» и таймкодами. Так появляется клик по фразе, который перематывает запись (см. «Задел» в PLAN.md у Reprise). Участники из календаря идут в `prompt`.

## 6. Дорожная карта

| Версия | Что входит |
|---|---|
| **0.1 — Слышит** | RefrainKit вынесен из Pretype, Pretype работает на нём без изменений. Приложение в строке меню с сервером: `json`, `text`, `verbose_json` с таймкодами сегментов. Проверки `Host` и `Origin`. Пресет в Reprise. **Готово, когда** Reprise транскрибирует часовой звонок на русском, наружу не уходит ни байта, а CPU и память в простое и в работе измерены и записаны в README |
| **0.2 — Слова** | Словарь в настройках, `prompt` → словарь, подсказка слов для Parakeet (если замер покажет выигрыш), таймкоды слов, `srt` и `vtt` |
| **0.3 — Кто говорит** | В Reprise `transcript.json` с «Вы / Собеседники» из двух дорожек. Диаризация внутри «Собеседников» (диаризатор FluidAudio) — по желанию, когда голосов больше одного |
| **0.4 — Часть системы** | App Intent *Transcribe File* для Shortcuts и Spotlight, через Shortcuts — Quick Action в Finder. Уступка диктовке (3.4), если замер покажет, что она нужна |
| **1.0** | Подписанный и нотаризованный релиз, обновление внутри приложения, как у Reprise, Homebrew cask, опубликованная таблица WER по языкам, сайт |

### Чего не будет

- Своей диктовки: это Pretype.
- Обработки текста через LLM, саммари и заметок.
- Облачных движков: для них есть Reprise и сами провайдеры.
- Синтеза речи (TTS), хотя он есть в FluidAudio.
- Windows и Linux. Только последняя macOS: 26 и новее.
- WhisperKit, пока кто-нибудь не попросит язык, которого нет ни у Apple, ни у Parakeet.

## 7. Риски и ограничения

- **Две копии модели в памяти.** Когда Pretype диктует, а Refrain транскрибирует, Parakeet загружен в обоих процессах: около 180 МБ вместо 90. Refrain выгружает модель в простое, поэтому так бывает редко. Если это станет проблемой, Pretype сможет диктовать через Refrain по XPC.
- **Локальный порт.** Любой процесс на Mac может к нему обратиться, и в этом смысл. Веб-страницы — нет: см. проверки `Host` и `Origin` в 3.2.
- **Лицензии моделей.** FluidAudio — Apache-2.0. Веса Parakeet от NVIDIA и Parakeet Ultra от moondream распространяются на своих условиях. До релиза нужно проверить обе лицензии и описать атрибуцию в `THIRD_PARTY_NOTICES`, как в Pretype.
- **FluidAudio быстро меняется** (0.17.x). Версия закрепляется через `.upToNextMinor`, как в Pretype.
- **Языковые пакеты Apple.** Первый запрос на новом языке ждёт, пока macOS скачает модель (`AssetInventory`). Этот запрос не должен молча упасть по таймауту клиента: у Reprise он 900 с. Резервирование локалей нужно освобождать: в Pretype утечка резерва уже была.
- **Порт занят.** Ошибка видна в строке меню и в настройках (3.2).

## 8. Сборка и релиз

```
whisper/
├── Package.swift        # библиотека RefrainKit
├── Sources/RefrainKit/ # движки, выбор по языку, словарь, таймкоды
├── Tests/RefrainKitTests/
├── project.yml          # приложение, XcodeGen, как у Reprise
├── Refrain/            # строка меню, сервер, настройки, Intents
└── docs/PLAN.md
```

- `Package.swift` лежит в корне репозитория. Пакет по URL подключается только так: SwiftPM не находит пакет в подпапке чужого репозитория. Pretype подключает RefrainKit по URL и версии, а во время разработки — по локальному пути.
- Приложение собирается так же, как Reprise: Xcode 27, Swift 6 со строгой конкурентностью, `xcodegen generate`, RefrainKit подключается как локальный пакет `.`.
- Релиз такой же, как у Reprise и Pretype: `Developer ID Application` → `notarytool submit` → `stapler staple` → `.zip` в GitHub Releases → Homebrew cask.
